# Manage Tracks

:::{admonition} Owner's Manage Tracks

The hackathon's tracks. Appears once the hackathon has a track. It shows:

- [Tracks](#tracks): each track with its description
- [A track](#a-track): add, edit or delete one

:::

![The Manage Tracks page of a hackathon, as its owner sees it](../static/screenshots/manage-tracks.png)

:::{admonition} Tracks are optional

Hackathons without tracks are perfectly fine. Add the first one on
[Settings](manage-settings.md).

:::

## Tracks

- Tracks group projects, for example by theme.
- A project picks its track when it is proposed or edited, see
  [Manage Projects](manage-projects.md).

## A track

- Click {guilabel}`New track` and enter a name and description.
- Click {guilabel}`Delete this track` to remove it. Its projects stay, without a
  track.
