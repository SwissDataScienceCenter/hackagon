# Manage Public Page

:::{admonition} Owner's Manage Public Page

The hackathon as everyone outside it sees it. It shows:

- [The form](#the-form): name, visibility, dates, logo and description
- [The preview](#the-preview): what visitors will see

:::

![The Manage Public Page page of a hackathon, as its owner sees it](../static/screenshots/manage-public.png)

## The form

- **Name**, **Visibility** (public or private), **Starts at**, **Ends at**,
  **Logo URL**, **Description**.
- Private hackathons are reached through [Invitations](manage-invites.md).
- Dates can be changed but not removed once set.
- **Save changes** returns to [Settings](manage-settings.md).

## The preview

- Updates as you type.
