# Manage Voting

:::{admonition} Owner's Manage Voting

Vote categories and results. It shows:

- [How voting works](#how-voting-works): the four steps and where each stands
- [Categories](#categories): what participants vote on
- [Count so far](#count-so-far): the live tally, for owners only

It might also show:

- [Final results](#final-results): once you make the results final

:::

![The Manage Voting page of a hackathon, as its owner sees it](../static/screenshots/manage-voting.png)

## How voting works

1. Set up the categories.
2. Open voting, then close it: **Participants can vote** on
   [Settings](manage-settings.md).
3. Make the results final, here.
4. Publish them: **Publish results** on [Settings](manage-settings.md).

## Categories

- **New category**: name, description and how people vote: **Single choice**
  (pick one) or **Points** (spread a budget, 10 by default).
- **Edit** and **Delete** until someone has voted in it; then it is **Locked**.
- Participants vote on [Voting](../participant/member-voting.md).

## Count so far

- The ranking per category as votes come in; participants don't see it.
- **Make results final**: only once voting is closed; it cannot be undone.

## Final results

- Participants see them on [Results](../participant/member-results.md) once you
  publish them.
