# Manage Projects

:::{admonition} Owner's Manage Projects

Every project, whatever its status. It shows:

- [Projects by status](#projects-by-status): approved, awaiting review, rejected
- [Review](#review): approve or reject a project
- [New project](#new-project): add one yourself

:::

![The Manage Projects page of a hackathon, as its owner sees it](../static/screenshots/manage-projects.png)

## Projects by status

- Tabs **Approved**, **Awaiting review**, **Rejected**.
- **Download CSV**: all projects.
- **Review** or **Edit** per project.

## Review

- **Approve**, **Reject** (with an optional reason), **Revoke approval** or
  **Reconsider**.
- Only approved projects appear on [Projects](../participant/member-projects.md)
  and on [Manage Teams](manage-teams.md).

## New project

- **New Project**: the same form participants use to propose.
- Participants propose only while you allow it, see
  [Settings](manage-settings.md).
