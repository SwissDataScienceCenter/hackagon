# Invitations

:::{admonition} Owner's Invitations

The links that let people into a private hackathon. Only for private hackathons.
It shows:

- [Live links](#live-links): links that work, to copy or revoke
- [New link](#new-link): create another one

It might also show:

- [No longer working](#no-longer-working): revoked and expired links

:::

![The Invitations page of a hackathon, as its owner sees it](../static/screenshots/manage-invites.png)

## Live links

- Copy a link into an email; **Revoke** it if it spreads.
- Someone with a valid link joins straight away, without the waitlist.
- Links work only while registration is open, see
  [Settings](manage-settings.md).

## New link

- An optional note on who it is for; **Create link**.
- A link stops working when the hackathon ends.

## No longer working

- Revoked or expired links, for reference.
