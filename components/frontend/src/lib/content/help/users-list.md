Platform roles:

- **Admin** — full access to every hackathon, and to user management.
- **Hackathon Organizer** — can create hackathons.

Roles within hackathons:

- **Owns** counts the hackathons a user owns.
- Participation isn't shown here yet; open a user to see it.

Open a user to change their platform role or see their involvement in
hackathons.
