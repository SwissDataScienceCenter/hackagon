- **None** — no platform role; can still own or take part in hackathons.
- **Hackathon Organizer** — can create hackathons.
- **Admin** — full access to every hackathon, and to user management.

A user holds one platform role at a time. Switching revokes the current role and
then grants the new one.

Platform roles are independent from the roles a user holds inside a hackathon,
such as owner or member.
